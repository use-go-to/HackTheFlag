Chronologie

Six étapes, du scan réseau au flag final. On suit toujours le même ordre : reconnaissance, énumération, exploitation, élévation.

Méthode exacte, en un coup d'œil

Élévation — python2.7 SUID → root

Un interpréteur SUID root donne un shell root immédiat.

ted@Toppo: ~
ted@Toppo:~$ python2.7 -c 'import os; os.setuid(0); os.system("/bin/bash")'
root@Toppo:~# whoami
root

root@Toppo:~# id
uid=0(root) gid=1000(ted) groups=1000(ted),24(cdrom),25(floppy),29(audio),30(dip),44(video),46(plugdev),108(netdev),114(bluetooth)

Ce qu'il faut vraiment comprendre

On énumère avant d'exploiter

Chaque étape produit une info qui guide la suivante. nmap donne les ports → gobuster donne les répertoires → notes.txt donne les creds → SSH donne un shell → find donne le SUID → le SUID donne root.

Un SUID anormal, c'est une porte ouverte

Sur Debian, python2.7 n'est jamais SUID root. Dès qu'un binaire interpréteur (python, perl, vim, less…) est SUID, il donne un shell root immédiat. Réflexe : comparer la liste SUID à ce qu'on attend.

Un mot de passe dans un fichier web est une fuite classique

Les répertoires /admin, /backup, /mail contiennent souvent des notes, des logs ou des exports oubliés. Toujours les lister après gobuster.

Terminal d'entraînement

Rejoue la chaîne complète, commande par commande. Le shell change d'utilisateur au fur et à mesure — comme sur la vraie machine. Explore librement : tu peux te balader dans l'arborescence, lire d'autres fichiers, rater des commandes.
